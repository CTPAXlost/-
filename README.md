# ЕЛЦ — Android-игра v1.0.1

Исправленная версия простой аркады для Android с тремя отдельными героями и мини-играми.

## Герои и режимы

- **Александр Ложкин** — ловит бутылки пакетом с четырёх направлений.
- **Алик Рак** — бросает поленья в котлы, которые появляются с четырёх сторон.
- **Андрей Королёв** — тушит очаги пожара, возникающие с четырёх сторон.

У каждого героя по **10 уровней**. С каждым уровнем сокращается время реакции, цели появляются чаще, а одновременно на экране может быть несколько объектов. На уровень даётся три жизни.

## Что исправлено в v1.0.1

- устранена ошибка Android Lint `ArrayList.sort requires API 24`;
- сохранена поддержка Android 6.0 и новее (`minSdk 23`);
- APK теперь собирается отдельным обязательным этапом до запуска Lint;
- готовый APK проверяется как ZIP-архив и на наличие `AndroidManifest.xml`, `classes.dex` и `resources.arsc`;
- даже при замечаниях Lint рабочий APK всё равно публикуется;
- отчёт Lint сохраняется отдельным артефактом;
- обновлены используемые GitHub Actions;
- версия приложения повышена до `1.0.1`.

## Что реализовано

- портретное меню «ЕЛЦ» по утверждённому макету;
- выбор одного из трёх персонажей нажатием на карточку;
- три разных игровых режима;
- 10 уровней для каждого героя;
- постепенное увеличение скорости и количества целей;
- очки, рекорды и сохранение прогресса;
- разделы «Рекорды», «Достижения», «Рейтинг», «Магазин»;
- настройки звука и вибрации;
- пауза, повтор игры и возврат в меню;
- полноэкранный портретный режим;
- автоматическая сборка APK через GitHub Actions.

## Как собрать APK через GitHub

1. Создай новый пустой репозиторий GitHub.
2. Распакуй архив проекта.
3. Загрузи в репозиторий **содержимое папки `ЕЛЦ — Android v1.0.1`**, а не саму внешнюю папку.
4. Проверь, что загрузилась скрытая папка `.github`.
5. Открой вкладку **Actions**.
6. Выбери workflow **«Сборка APK ЕЛЦ»**.
7. Нажми **Run workflow**.
8. После завершения скачай артефакт **«ЕЛЦ — готовый APK v1.0.1»**.
9. Внутри находятся:
   - `ЕЛЦ-v1.0.1.apk`;
   - `ЕЛЦ-v1.0.1.sha256.txt`.

Основной этап сборки должен быть зелёным. Этап Android Lint может отображать предупреждение, но он больше не блокирует выдачу APK; подробный отчёт загружается отдельно.

## Управление

### Александр Ложкин

Нажимай на одну из четырёх зон экрана: слева сверху, слева снизу, справа сверху или справа снизу. Пакет переместится в выбранную сторону.

### Алик Рак

Когда появляется котёл, нажми на соответствующую сторону экрана. Герой бросит туда полено.

### Андрей Королёв

Когда появляется огонь, нажми на соответствующую сторону. Герой направит туда струю воды.

## Основные файлы

- `app/src/main/java/ru/elc/arcade/GameView.java` — игровая логика, меню и отрисовка;
- `app/src/main/java/ru/elc/arcade/MainActivity.java` — запуск и полноэкранный режим;
- `app/src/main/res/drawable-nodpi/menu_elc.png` — утверждённое меню;
- `.github/workflows/сборка-apk.yml` — надёжная сборка и публикация APK.
