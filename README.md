# Лови бутылки — Android

Простая аркадная игра в духе классической игры, где волк ловит яйца.

Главный герой стоит между двумя магазинами и ловит бутылки в пакет. У бутылок четыре направления: слева сверху, слева снизу, справа сверху и справа снизу.

## Уже работает в версии 0.1.0

- главный персонаж из приложенной фотографии;
- два магазина по краям экрана;
- четыре направления падения бутылок;
- управление четырьмя большими кнопками;
- пакет перемещается в выбранный угол;
- обычные и золотые бутылки;
- 10 уровней;
- на каждом уровне повышаются скорость, частота и количество бутылок одновременно;
- три ошибки на уровень;
- очки и сохранение рекорда;
- пауза;
- экран победы после десятого уровня;
- сборка APK через GitHub Actions.

## Как собрать APK на GitHub

1. Создайте пустой репозиторий на GitHub.
2. Загрузите в него **всё содержимое этой папки**, включая скрытую папку `.github`.
3. Откройте вкладку **Actions**.
4. Выберите **Сборка APK**.
5. Нажмите **Run workflow**.
6. После завершения откройте запуск и скачайте артефакт **Лови бутылки — APK**.
7. Внутри будет файл `Лови бутылки v0.1.0-debug.apk`.

Сборка также запускается автоматически после каждого изменения в ветке `main` или `master`.

## Управление

- левая верхняя кнопка — пакет слева сверху;
- левая нижняя кнопка — пакет слева снизу;
- правая верхняя кнопка — пакет справа сверху;
- правая нижняя кнопка — пакет справа снизу;
- кнопка паузы находится в правом верхнем углу.

## Техническая основа

- Java;
- собственный игровой экран на Android Canvas;
- без игровых движков и тяжёлых библиотек;
- Android 7.0 и новее;
- Android Gradle Plugin 9.3.0;
- Gradle 9.5.0;
- Java 17.

## Где менять баланс уровней

Файл:

`app/src/main/java/ru/lovibutilki/game/GameView.java`

Основные методы:

- `targetForLevel()` — сколько бутылок нужно поймать;
- `spawnIntervalMs()` — как часто появляются бутылки;
- `travelDurationMs()` — скорость движения;
- `maxActiveBottles()` — сколько бутылок может лететь одновременно.
