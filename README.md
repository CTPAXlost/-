# ЕЛЦ — Android v2.2.0

Простая аркада в духе «Ну, погоди! Волк ловит яйца» с тремя отдельными режимами.

## Герои

1. Александр Ложкин ловит бутылки пакетом в четырёх положениях.
2. Алик Рак бросает поленья в котлы, появляющиеся в четырёх зонах.
3. Андрей Королёв тушит очаги пожара в четырёх зонах.

У каждого героя 10 уровней. С каждым уровнем сокращается время реакции и увеличивается число одновременно активных объектов.

## Новое в v2.2.0

- добавлен второй весёлый скин каждому герою за 200 монет:
  - Александр Ложкин — «Праздничный ловец»;
  - Алик Рак — «Супер-Алик»;
  - Андрей Королёв — «Пляжный пожарный»;
- оригинальные костюмы за 100 монет сохранены;
- в магазине можно покупать и переключать оба вида скинов;
- после завершения уровня запускается плавная финальная сценка, затем следующий уровень начинается автоматически;
- Александр пьёт из бутылки и комично падает;
- Алик бросает полено прямо в экран;
- Андрей радостно поливает экран водой из шланга;
- монеты начисляются за успешные действия и прохождение уровней.

## Сборка через GitHub

1. Создайте пустой репозиторий GitHub.
2. Загрузите всё содержимое этой папки, включая скрытую папку `.github`.
3. Откройте вкладку `Actions`.
4. Выберите `Сборка и проверка APK ЕЛЦ`.
5. Нажмите `Run workflow`.
6. После зелёного завершения скачайте артефакт `ЕЛЦ — проверенный APK v2.2.0`.

Готовый файл называется `ЕЛЦ-v2.2.0.apk`.

Сборку v2.2.0 можно устанавливать поверх v2.1.0, поскольку используется тот же пакет и ключ подписи.
