# ЕЛЦ — Android v1.1.0

Простая аркадная игра для Android с тремя героями и тремя игровыми режимами.

## Герои

- Александр Ложкин — ловит бутылки пакетом.
- Алик Рак — кидает поленья в появляющиеся котлы.
- Андрей Королёв — тушит очаги пожара.

У каждого героя 10 уровней. На следующих уровнях объекты появляются чаще, времени на реакцию становится меньше, а одновременно активных целей становится больше.

## Что исправлено в v1.1.0

- Исправлена отрисовка шкалы прогресса при нулевом значении.
- Убрана инициализация звука до первого действия пользователя.
- Добавлен отдельный экран правил перед стартом каждого режима.
- Добавлены хорошо заметные четыре зоны управления.
- Добавлено восстановление игрового экрана при ошибке отрисовки вместо мгновенного закрытия приложения.
- Исправлена работа меню при резервной отрисовке.
- APK теперь подписывается одним и тем же проектным ключом, поэтому будущие версии можно будет устанавливать поверх v1.1.0.
- GitHub Actions не только собирает APK, но и запускает его в Android-эмуляторе, открывает меню, запускает всех трёх героев и проверяет журнал на падения.

## Как собрать APK через GitHub

1. Удалите старые файлы из репозитория.
2. Загрузите содержимое этой папки в корень репозитория, включая скрытую папку `.github`.
3. Откройте вкладку **Actions**.
4. Выберите **Сборка и проверка ЕЛЦ**.
5. Нажмите **Run workflow**.
6. Дождитесь зелёной галочки.
7. Скачайте артефакт **ЕЛЦ — проверенный APK v1.1.0**.

Внутри будет `ЕЛЦ-v1.1.0.apk` и файл контрольной суммы.

## Важно при установке

Версия v1.0.1 была подписана временным ключом GitHub. Поэтому перед первой установкой v1.1.0 нужно удалить старую игру **ЕЛЦ** с телефона. Начиная с v1.1.0 последующие сборки будут подписываться постоянным ключом из проекта и смогут обновляться поверх установленной версии.

## Проверка GitHub Actions

При успешной сборке второй артефакт **ЕЛЦ — проверка запуска v1.1.0** содержит:

- скриншот главного меню;
- экран правил Александра;
- игровой экран Александра;
- игровой экран Алика;
- игровой экран Андрея;
- `logcat.txt` с журналом Android;
- отчёт Android Lint.
