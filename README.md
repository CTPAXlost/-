# ЕЛЦ — Android-игра

Рабочий проект простой аркады для Android с тремя отдельными героями и мини-играми.

## Герои и режимы

- **Александр Ложкин** — ловит бутылки пакетом с четырёх направлений.
- **Алик Рак** — бросает поленья в котлы, которые появляются с четырёх сторон.
- **Андрей Королёв** — тушит очаги пожара, возникающие с четырёх сторон.

У каждого героя по **10 уровней**. С каждым уровнем сокращается время реакции, предметы появляются чаще и одновременно может быть несколько целей. На уровне даётся три жизни.

## Что реализовано

- портретное меню «ЕЛЦ» по утверждённому макету;
- выбор одного из трёх персонажей нажатием на карточку;
- три разных игровых режима;
- 10 уровней для каждого героя;
- очки, рекорды и сохранение прогресса;
- разделы «Рекорды», «Достижения», «Рейтинг», «Магазин»;
- настройки звука и вибрации;
- пауза, повтор уровня, возврат в меню;
- полноэкранный портретный режим;
- поддержка Android 6.0 и новее;
- автоматическая проверка и сборка APK через GitHub Actions.

## Как собрать APK через GitHub

1. Создайте новый пустой репозиторий GitHub.
2. Распакуйте архив проекта.
3. Загрузите в репозиторий **содержимое папки проекта**, а не саму внешнюю папку.
4. Проверьте, что загрузилась скрытая папка `.github`.
5. Откройте вкладку **Actions**.
6. Выберите workflow **«Сборка APK ЕЛЦ»**.
7. Нажмите **Run workflow**.
8. После зелёной галочки откройте запуск и скачайте артефакт **«ЕЛЦ — готовый APK»**.
9. Внутри находится файл `ЕЛЦ-v1.0.0.apk` и его SHA-256.

Сборка также запускается автоматически при каждом push в `main` или `master`.

## Почему эта сборка надёжнее предыдущей

- используется существующая стабильная версия Android Gradle Plugin `8.9.2`;
- Gradle зафиксирован на совместимой версии `8.11.1`;
- Java зафиксирована на версии `17`;
- workflow самостоятельно устанавливает Android SDK 35 и Build Tools 35.0.0;
- перед публикацией APK запускается Android Lint;
- workflow проверяет, что APK действительно создан и не пустой;
- в коде звук и вибрация изолированы так, чтобы их сбой не завершал игру.

## Управление

### Александр Ложкин

Нажмите на одну из четырёх зон экрана: слева сверху, слева снизу, справа сверху или справа снизу. Пакет переместится в выбранную сторону.

### Алик Рак

Когда появляется котёл, нажмите на соответствующую сторону экрана. Герой бросит туда полено.

### Андрей Королёв

Когда появляется огонь, нажмите на соответствующую сторону. Герой направит туда струю воды.

## Основные файлы

- `app/src/main/java/ru/elc/arcade/GameView.java` — игровая логика, меню и отрисовка;
- `app/src/main/java/ru/elc/arcade/MainActivity.java` — запуск и полноэкранный режим;
- `app/src/main/res/drawable-nodpi/menu_elc.png` — утверждённое меню;
- `.github/workflows/сборка-apk.yml` — сборка APK на GitHub.
