# ЕЛЦ v1.2.0

Простая аркадная Android-игра с тремя героями:

- Александр Ложкин ловит бутылки пакетом;
- Алик Рак кидает поленья в появляющиеся котлы;
- Андрей Королёв тушит очаги пожара.

У каждого героя 10 уровней. С каждым уровнем уменьшается время реакции и увеличивается число одновременных целей.

## Сборка APK через GitHub

1. Создайте пустой репозиторий GitHub.
2. Загрузите в корень репозитория всё содержимое этой папки, включая `.github`, `app`, `scripts` и `keystore`.
3. Откройте вкладку **Actions**.
4. Выберите **Сборка APK ЕЛЦ**.
5. Нажмите **Run workflow**.
6. Скачайте артефакт **ЕЛЦ — APK v1.2.0**.
7. Внутри находится `ЕЛЦ-v1.2.0.apk`.

Главная сборка APK больше не блокируется из-за нестабильности облачного Android-эмулятора. Эмулятор запускается после публикации APK как дополнительная проверка и сохраняет журнал и скриншоты.

Перед установкой рекомендуется удалить старые тестовые версии ЕЛЦ, если Android сообщает о конфликте подписи.
