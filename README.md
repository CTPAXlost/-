# ЕЛЦ — Android v2.1.0

Полностью переделанная простая аркада в духе «Ну, погоди! Волк ловит яйца».

## Главное отличие от старой версии

В игровом поле больше нет карточки персонажа из меню. Каждый герой отображается отдельной небольшой фигурой:

- лицо и головной убор взяты из подготовленного портрета;
- корпус, ноги, руки и рабочий инструмент рисуются отдельно;
- фигура смещается и наклоняется к выбранной стороне;
- у Александра двигается положение пакета;
- у Алика есть короткая анимация броска полена;
- у Андрея поворачивается рукав и появляется струя воды.

## Режимы

1. Александр Ложкин — ловит бутылки пакетом в четырёх положениях.
2. Алик Рак — бросает поленья в котлы, появляющиеся в четырёх зонах.
3. Андрей Королёв — тушит очаги пожара в четырёх зонах.

У каждого героя 10 уровней. С каждым уровнем сокращается время реакции, увеличивается частота появления целей и число одновременно активных объектов.

## Сборка через GitHub

1. Создайте пустой репозиторий GitHub.
2. Загрузите всё содержимое этой папки, включая скрытую папку `.github`.
3. Откройте вкладку `Actions`.
4. Выберите `Сборка и проверка APK ЕЛЦ`.
5. Нажмите `Run workflow`.
6. После зелёного завершения скачайте артефакт `ЕЛЦ — проверенный APK v2.1.0`.

Workflow не только собирает APK, но и запускает приложение в Android-эмуляторе, открывает меню, последовательно запускает всех трёх героев, нажимает четыре игровые зоны и сохраняет скриншоты.

## APK

Готовый файл в артефакте называется `ЕЛЦ-v2.1.0.apk`.

Старые версии приложения перед установкой лучше удалить, поскольку у них использовались другие идентификаторы пакета и варианты подписи.
