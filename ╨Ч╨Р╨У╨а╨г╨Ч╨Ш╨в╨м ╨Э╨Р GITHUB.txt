1. Полностью очистить старый репозиторий или создать новый пустой.
2. Загрузить СОДЕРЖИМОЕ папки «ЕЛЦ — Android v2.2.0».
3. Проверить, что на GitHub видна папка .github/workflows.
4. Открыть Actions → «Сборка и проверка APK ЕЛЦ» → Run workflow.
5. Дождаться зелёной галочки.
6. Скачать артефакт «ЕЛЦ — проверенный APK v2.2.0».
7. Установить файл ЕЛЦ-v2.2.0.apk.

Версию v2.2.0 устанавливать поверх v2.1.0, чтобы сохранить монеты и купленные скины.
