ЕЛЦ v1.1.1

1. Удалите старое содержимое репозитория.
2. Загрузите ВСЁ содержимое папки «ЕЛЦ — Android v1.1.1» в корень репозитория.
3. Не забудьте скрытую папку .github.
4. Откройте Actions → «Сборка и проверка ЕЛЦ» → Run workflow.
5. Дождитесь зелёной галочки.
6. Скачайте артефакт «ЕЛЦ — проверенный APK v1.1.1».

Перед установкой удалите с телефона старую версию v1.0.1, потому что она была подписана другим временным ключом.
Начиная с v1.1.1 будущие версии можно будет устанавливать поверх игры без удаления.
