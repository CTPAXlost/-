ЕЛЦ v1.0.1 — СБОРКА APK

1. Распакуй архив.
2. Создай пустой репозиторий GitHub.
3. Загрузи ВЕСЬ контент папки «ЕЛЦ — Android v1.0.1», включая скрытую папку .github.
4. Открой Actions → «Сборка APK ЕЛЦ» → Run workflow.
5. После завершения скачай артефакт «ЕЛЦ — готовый APK v1.0.1».
6. Установочный файл внутри: ЕЛЦ-v1.0.1.apk

Важно: больше не используй файлы старой версии v1.0.0 — замени содержимое репозитория полностью.
