1. Распакуй архив.
2. Создай пустой репозиторий GitHub.
3. Загрузи ВЕСЬ контент папки «ЕЛЦ — Android v1.0.0», включая скрытую папку .github.
4. Открой Actions → «Сборка APK ЕЛЦ» → Run workflow.
5. После зелёной галочки скачай артефакт «ЕЛЦ — готовый APK».
6. Установочный файл внутри: ЕЛЦ-v1.0.0.apk
