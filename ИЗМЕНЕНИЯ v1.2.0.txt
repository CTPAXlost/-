ЕЛЦ v1.2.0

Исправлено:
- GitHub больше не пытается запускать приложение через ненадёжную команду monkey;
- пакет и стартовая Activity определяются непосредственно из собранного APK;
- приложение запускается явной командой am start;
- тестовые режимы открываются специальной командой только в Debug-сборке;
- проверяются меню и игры Александра, Алика и Андрея;
- при ошибке сохраняются logcat, состояние Activity и скриншоты;
- готовый Release APK публикуется до запуска облачного эмулятора;
- сбой инфраструктуры эмулятора больше не блокирует скачивание APK;
- меню декодируется в экономичном RGB_565 и имеет резервный вариант при нехватке памяти;
- версия приложения обновлена до 1.2.0.
